# Pastel Palette Studio

A simple artistic pastel colour palette generator built with HTML, CSS and JavaScript.

## Features
- Pastel palettes with blue, green, yellow, peach and lavender tones
- Mood-based palettes
- Random palette generator
- Click a colour to copy its HEX code
- Responsive design
- No backend, database, npm or installation required

## Run
Open `index.html` in Chrome.

## GitHub Pages
Upload all four files to a GitHub repository. Then go to **Settings → Pages → Deploy from a branch**, select your main branch and `/ (root)`, and save.

The website entry point is `index.html`.
